## Installation

```bash
git clone https://github.com/itsmesatyavir/stobix
cd stobix
npm install
nano .env
```

Edit the `.env` file and add your private keys:

```
PRIVATE_KEY_1=your_first_private_key
PRIVATE_KEY_2=your_second_private_key
```

(Optional) Add your proxies to `proxies.txt`, one per line:

```
http://username:password@proxy1.example.com:8080
username:password@proxy2.example.com:8080
```

## Usage

Start the bot using:

```bash
node main
```

**The bot will:**

1. Load and loop through all wallet keys  
2. Claim available social tasks  
3. Start mining if not already active  
4. Check mining status every hour  
5. Retry on failures automatically
